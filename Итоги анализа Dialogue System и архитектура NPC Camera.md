# **Архитектурный анализ и спецификация диалоговой системы и камеры NPC**

Данный документ содержит консолидированные итоги технического ревью компонентов диалоговой системы (DialogueScreen.java, NarrativeOverlay.java) и подробную архитектурную спецификацию механизма наведения камеры на NPC во время диалога.

## **1\. Итоги код-ревью и статус компонентов**

### **DialogueScreen.java**

> * **Layout и конфигурация:** Список ответов не захардкожен внизу экрана. Метод layoutResponses() корректно берет координаты из MenuCustomizationConfig.dialogueResponseX() и dialogueResponseY(). Плашка имени с нахлестом в 1px и акцентной полосой сверху функционирует согласно дизайну.  
> * **Рассинхронизация по Escape (Критично):** Метод onClose() восстанавливает hideGui и вызывает super.onClose(), но не отправляет серверу C2S-пакет об отмене/выходе. Сессия DialogueSession на стороне сервера остается активной.  
>   *Решение:* Добавить отправку пакета отмены в onClose(), симметрично методу select().  
> * **Null Safety:** Поля payload.responses и payload.text требуют явной проверки на null перед вызовами .size() и .append(), либо гарантии на уровне сетевого кодека в DialogueNetworking.java.  
> * **Тайпврайтер:** Вызов typewriter.tick() внутри Screen.tick() реализован штатно без необходимости глобальных хуков.

### **NarrativeOverlay.java**

> * **ClientChatReceivedEvent:** Перехват успешно исключен.  
> * **Размер окна:** Ширина boxWidth рассчитывается динамически от общей длины контента, а не фиксированной константой. Баг с дергающейся рамкой устранен (расчет идет от полного текста, а не текущего кадра).  
> * **Стилизация:** Отрисовка выполняется через плоскую полупрозрачную заливку TextureBlitHelper.fillBox(..., 0xB0101018) без текстуры quest\_menu.png.  
> * **Позиционирование:** Добавлено корректное вертикальное центрирование иконки и имени относительно блока текста.  
> * **Null Safety фикс:** Вызов Component fullText \= message.getText(); требует защиты от NPE:  
>   `Component fullText = message.getText() == null ? Component.empty() : message.getText();`

## **2\. Архитектура системы наведения камеры на NPC**

Ключевой принцип: **системе не требуется постоянный статический ID сущности**. Привязка существует исключительно в рамках одной активной диалоговой сессии (от открытия до закрытия окна диалога).

### **2.1. Схема передачи контекста сущности**

| Компонент / Этап | Механизм реализации | Назначение   |
| :---- | :---- | :---- |
| **Команда старта** | /dialogue start \<player\> \<id\> \[nodeId\] \[npcSelector\] | Принимает селектор сущности через ванильный EntityArgument.entity(). |
| **Источники вызова** | HollowEngine-скрипты, командные блоки, триггеры других модов | Передают живой UUID или селектор (например, @e\[tag=barman,limit=1,sort=nearest\]). |
| **Универсальность** | Базовый класс net.minecraft.world.entity.Entity | Работает с любыми мобами/NPC из любых модов и ванильными сущностями. |
| **Сетевой пакет** | S2COpenDialoguePacket | Передает координаты/позицию взгляда NPC клиенту для локальной интерполяции. |

### **2.2. Обработка краевых случаев**

> * **Отсутствие NPC (Нарратив / Голос за кадром):** Аргумент npcSelector является опциональным. Если сущность не передана, диалог открывается в стандартном режиме без смещения камеры.  
> * **Деспавн или удаление NPC во время диалога:** В сессии хранится UUID, а не жесткая ссылка на объект. При валидации ((ServerLevel) level).getEntity(npcUuid) в случае null слежение плавно отключается, возвращая камеру к игроку без прерывания текста диалога.  
> * **Пересоздание сущности:** При новом запуске диалога передается актуальный UUID момента взаимодействия, что исключает рассинхронизацию после рестартов.

## **3\. Клиентская реализация (DialogueCameraController)**

> * **Рендеринг камеры:** Не модифицирует физическое положение игрока. Интерполяция выполняется в событии EntityViewRenderEvent.CameraSetup.  
> * **Плавность (Lerp):** Камера плавно переходит от исходного ракурса игрока к целевой точке NPC за заданное количество тиков при открытии экрана и возвращается обратно при закрытии диалога.
