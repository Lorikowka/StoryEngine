# Story Engine

**Сюжетный движок для Minecraft (Forge 1.19.2).**

Story Engine — это модульный инструментарий для создания интерактивных
историй прямо в игре. Он даёт серверу и авторам сюжетов две ключевые
системы, которые не требуют перезапуска мира:

- **Журнал квестов** — квесты описываются в JSON, их прогресс у каждого
  игрока отслеживается автоматически (сбор предметов, добыча блоков,
  убийство мобов, посещение точек), а сами квесты можно создавать,
  менять и завершать командами оператора на лету.
- **Сюжетный чат (Narrative HUD)** — сервер отправляет реплики NPC с
  именем и иконкой, которые появляются снизу по центру экрана с
  эффектом печатной машинки, как в диалоговых RPG.
  - **Диалоги (Dialogue System)** — ветвящиеся диалоги с условиями,
    вариантами ответа и действиями. Папка = диалог, файл = узел; ленивая
    загрузка с диска, hot-reload, минималистичный GUI с печатной машинкой
    (нижняя панель во всю ширину, без иконок/портретов).

Всё это работает **без правки кода и без перезагрузки сервера**: тексты,
цели и иконки меняются командами и/или правкой файлов в папке `config`.

---

## Возможности

- **JSON-квесты** с 5 типами подзадач (ручные и автоотслеживаемые).
- **Персональный прогресс** каждого игрока (переживает смерть и смену
  измерения).
- **Редактирование на лету** — меняйте название, описание и цели квеста
  командой, и все онлайн-игроки увидят изменения мгновенно.
- **Сюжетный чат** с иконками NPC (PNG с диска), очередью реплик и
  анимацией печати.
- **Клиентский GUI квестов** по клавише `J` с вкладками
  Активные / Завершённые / Проваленные.
- **Полная кастомизация интерфейса** — текстуры PNG и цвета/масштаб
  через конфиг, без пересборки мода.
- **Награды** — команды, опыт и предметы при завершении квеста.

## Установка

1. Скачайте/соберите `story_engine-<версия>.jar` (см. «Сборка из
   исходников»).
2. Поместите его в папку `mods/` вашего клиента и/или сервера.
3. Запустите игру. Папка `config/story_engine/` создастся автоматически
   со всеми подпапками и исходными текстурами меню.

> **Требования:** Minecraft 1.19.2 + Forge 43.5.x. Java 17.

## Быстрый старт

```text
# создать шаблон квеста и открыть его в config/story_engine/quests/
/quest create find_key "Потерянный ключ"

# выдать квест игроку
/quest start Steve find_key

# послать сюжетную реплику всем игрокам
/storytell @a "Староста" old_man {"text":"Ключ спрятан под мельницей."}

# открыть журнал квестов
нажмите J
```

## Команды

Все команды требуют прав оператора (**permission level 2**, как
`/gamemode`). ID и имена подзадач поддерживают автодополнение по `Tab`.

### `/quest` — управление квестами

| Команда | Назначение |
| --- | --- |
| `/quest create <id> [title]` | Создать шаблон JSON-квеста. |
| `/quest reload` | Перечитать все квесты с диска. |
| `/quest list` | Список загруженных квестов. |
| `/quest edit <id> title <text>` | Сменить название квеста на лету. |
| `/quest edit <id> description <text>` | Сменить описание квеста на лету. |
| `/quest start <player> <id>` | Начать квест у игрока. |
| `/quest complete <player> <id>` | Завершить, выдать награды. |
| `/quest fail <player> <id>` | Провалить квест. |
| `/quest reset <player> <id>` | Сбросить статус и прогресс. |

### `/quest task` — подзадачи

```text
/quest task add manual   <questId> <taskId> <title...>
/quest task add location <questId> <taskId> <dim> <x> <y> <z> <r> <title...>
/quest task add item     <questId> <taskId> <itemId> <count> <title...>
/quest task add block    <questId> <taskId> <blockId> <count> <title...>
/quest task add kill     <questId> <taskId> <entityType> <count> <title...>

/quest task remove <questId> <taskId>
/quest task edit <questId> <taskId> title <text>
/quest task edit <questId> <taskId> description <text>
/quest task complete <player> <questId> <taskId>
```

`/quest task add/remove/edit` сохраняют квест на диск и сразу
рассылают обновление всем онлайн-игрокам.

### `/storytell` — сюжетная реплика

```text
/storytell <players> <speaker> <icon> <message>
```

- `<players>` — получатели (например `@a`, `@p`, `Steve`);
- `<speaker>` — имя говорящего (в кавычках при пробелах: `"Староста"`);
- `<icon>` — имя PNG-иконки без расширения (`old_man`) или `none`;
- `<message>` — JSON-текст, как в `/tellraw`
  (`{"text":"Привет!","color":"gold"}`).

### `/storymenu` — текстуры меню

| Команда | Назначение |
| --- | --- |
| `/storymenu reset` | Вернуть PNG меню к исходным. |
| `/storymenu reload` | Сбросить кэш текстур на клиентах (подхватить правки). |

### `/dialogue` — диалоги

| Команда | Назначение |
| --- | --- |
| `/dialogue create <id> [title]` | Создать папку диалога + `_meta.json` + `entry.json`. |
| `/dialogue reload` | Перечитать все диалоги с диска (hot-reload). |
| `/dialogue list` | Список загруженных диалогов. |
| `/dialogue start <player> <id> [nodeId]` | Начать диалог (default: `entry` из `_meta`). |
| `/dialogue stop <player>` | Прервать активный диалог. |

Диалоги описываются JSON в `config/story_engine/dialogues/` (папка =
диалог, файл = узел). Подробности и формат узла/ответов/условий — в
`docs/DIALOGUE_SYSTEM.md`.

## Система квестов

Квесты хранятся в `config/story_engine/quests/<id>.json`. Имя файла
должно совпадать с полем `id` квеста.

### Формат JSON

```json
{
  "id": "find_key",
  "title": "Потерянный ключ",
  "description": "Найдите ключ под старой мельницей.",
  "prerequisites": ["first_quest"],
  "tasks": [
    { "id": "reach_mill", "title": "Дойдите до мельницы",
      "type": "LOCATION",
      "dimension": "minecraft:overworld", "x": 120, "y": 64, "z": -30, "radius": 4 }
  ],
  "rewards": {
    "commands": ["say Квест выполнен!"],
    "experience": 10,
    "items": [{ "id": "minecraft:diamond", "count": 2, "nbt": "{}" }]
  }
}
```

### Типы подзадач

| type | Автоотслеживание | Ключевые поля |
| --- | --- | --- |
| `MANUAL` | **нет** — только вручную | — |
| `LOCATION` | да (позиция игрока) | `dimension`, `x`, `y`, `z`, `radius` |
| `ITEM` | да (инвентарь) | `target`, `count`, `consume` |
| `BLOCK_BREAK` | да (ломание блоков) | `blockId`, `count` |
| `KILL_ENTITY` | да (убийство моба) | `entityType`, `count` |

> **Важно про `MANUAL`:** такая задача никогда не завершается сама —
> только явно через `/quest task complete` или `/quest complete`. Это
> осознанное поведение, чтобы ручные этапы (диалоги, выбор игрока) не
> «проскакивали» автоматически.

### Статусы у игрока

```
NOT_STARTED → ACTIVE → COMPLETED / FAILED
```

Статус и прогресс подзадач хранятся в Capability на каждого игрока и
переживают смерть и смену измерения.

### Журнал (клавиша `J`)

Двухпанельный экран: слева — вкладки и список квестов, справа — название,
описание и чек-лист подзадач. Данные приходят с сервера целиком при
каждом изменении; клиент не читает JSON напрямую.

## Сюжетный чат (Narrative HUD)

`/storytell` отправляет реплику, которая рисуется снизу по центру экрана
(`Y = высота − 60`, блок 300px):

- слева — иконка NPC 32×32 (если задана);
- сверху справа — имя говорящего (жёлтым);
- ниже — текст с автопереносом.

Несколько реплик подряд выстраиваются в **очередь** и показываются одна
за другой. Текст печатается посимвольно (~20 симв./сек), затем держится
на экране и сменяется следующим.

**Иконки NPC** кладутся в `config/story_engine/heads/<icon>.png`. Они
читаются прямо с диска (в обход ресурс-паков), результат кэшируется.
Если иконки нет или указано `none` — рисуется только текст.

> **Особенность анимации:** пока текст печатается, форматирование
> упрощается до единого стиля сообщения. Как только реплика допечатана
> целиком, выводится исходный JSON-компонент со всеми цветами/стилями,
> как в `/tellraw`. Если нужны разноцветные фрагменты во время печати —
> пошлите несколько `/storytell` подряд с разными цветами.

## Кастомизация меню квестов

Меню можно перекрасить и перерисовать без правки кода.

### Текстуры

При первом запуске мод копирует исходные PNG в `config/story_engine/menu/`:

- `quest_menu.png` — фон окна;
- `quest_widgets.png` — вкладки, строки списка, кнопка закрытия;
- `quest_icon.png` — иконка заголовка квеста;
- `status_active.png`, `status_completed.png`, `status_failed.png` —
  иконки вкладок.

Отредактируйте нужный файл. Чтобы изменения подхватились без
перезапуска — **Моды → Story Engine → Config** (сохранение перезагружает
конфиг) или `/storymenu reload`. Вернуть исходники — `/storymenu reset`.
Если кастомного файла нет или он битый, меню использует встроенную
текстуру.

### Цвета и масштаб

Задаются в `config/story_engine-client.toml` (раздел
`menuCustomization`), доступном и в игре через **Моды → Story Engine →
Config**:

- `enabled` — выключить кастомизацию вообще;
- `colors.*` — цвета в формате ARGB (`0xAARRGGBB`, 8 hex-цифр),
  например `0xFFF6D57A`;
- `layout.uiScaleOverride` — фиксированный масштаб (`0.0` = авто);
- `layout.fontScale` — множитель масштаба заголовка квеста.

## Структура конфигов

```
config/story_engine/
├── quests/                 # JSON-описания квестов
├── heads/                  # PNG-иконки NPC для /storytell
├── menu/                   # PNG-текстуры меню (кастомизация)
├── narrative_config.json
└── story_engine-client.toml   # настройки кастомизации меню
```

## Сборка из исходников

Требуется JDK 17 и интернет для загрузки зависимостей ForgeGradle.

```bash
./gradlew build
# готовый jar: build/libs/story_engine-<версия>.jar
```

Запуск игры из IDE (для разработки):

```bash
./gradlew runClient        # клиент
./gradlew runServer        # сервер (--nogui)
```

Тесты модели квестов (JUnit 5):

```bash
./gradlew test
```

## Заметки разработчика

- Подробности реализации каждой системы — в папке `docs/`
  (`QUEST_SYSTEM.md`, `NARRATIVE_HUD.md`, `DIALOGUE_SYSTEM.md`, `DEVLOG-2026-08-ui.md`).
- Квесты синхронизируются через `S2CSyncQuestDataPacket` (полный снимок
  квестов + статус игрока).
- Иконки NPC регистрируются как `DynamicTexture` под
  `story_engine:heads/<icon_id>` и читаются с диска через
  `NativeImage.read()`.
- Чтобы добавить новый тип подзадачи — создайте класс-наследник
  `QuestTask`, зарегистрируйте его в `QuestTask.Serializer` и при
  необходимости добавьте отслеживание в `QuestProgressTracker`.
