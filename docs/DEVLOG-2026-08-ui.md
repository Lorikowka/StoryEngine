# DEVLOG — UI (2026-08)

Работа над пользовательским интерфейсом мода Story Engine за август 2026 года.

- **Dialogue System v4 GUI** — нижняя панель ответов, табличка говорящего (speaker plate), эффект печатной машинки (typewriter) и кнопки вариантов ответа.
- **Narrative HUD** — исторический чат в центре снизу экрана с головами NPC и очередью сообщений с эффектом печатной машинки.
- **Quest Screen** — меню квестов, открываемое по клавише J.
- **Interaction Hint System** — HUD «[F] Действие» у интерактиблов мире, кольца-маркеры близких целей и F-фолбэк на ванильное использование. (JSON-меню взаимодействия из ранних версий вынесено, теперь это генеральные подсказки.)
