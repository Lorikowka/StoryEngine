# Story Engine — Interaction System
## Проектный документ модуля интерактивных триггеров (v2 — Green Bottom-Left UI)

---

## 1. Концепция

**Interaction System** — 4-й модуль Story Engine, отвечающий за контекстное взаимодействие с объектами и блоками в мире в стилистике современных action/RPG (Cyberpunk 2077, Deus Ex).

**Ключевые принципы:**
* **Плавная контекстность:** При наведении взгляда на целевой объект блок подсвечивается изумрудным контуром, а в **левом нижнем углу экрана** появляется неоново-зеленое меню взаимодействия.
* **Управление колесом мыши:** Навигация по списку действий осуществляется скроллом (`Mouse Scroll Up/Down`) с временной блокировкой переключения хотбара.
* **Подтверждение действия:** Активация выбранного пункта по нажатию клавиши взаимодействия (по умолчанию `F` или `ПКМ`).
* **Условия и валидация:** Полная поддержка синтаксиса условий `if` из Dialogue System. Выполнение проверяется на стороне сервера.

## 2. Пользовательский интерфейс (UI Layout)

### Схема экрана

```text
+------------------------------------------------------------------------------------+
|                                                                                    |
|                                     +---------+                                    |
|                                     |  Блок   |  <- Зеленая контурная подсветка    |
|                                     +---------+                                    |
|                                          + (Прицел)                                |
|                                                                                    |
|                                                                                    |
|  // ПАНЕЛЬ ВЗАИМОДЕЙСТВИЯ //                                                       |
|  +-------------------------------------+                                           |
|  | [E] ОБЪЕКТ: ДРЕВНИЙ СУНДУК          |  <- Шапка панели (Имя объекта)            |
|  +-------------------------------------+                                           |
|  | [>] 1. Осмотреть замок              |  <- Активный выбор (Ярко-зеленый фон)     |
|  | [ ] 2. Взломать отмычкой            |  <- Доступно (Темно-зеленый)              |
|  | [x] 3. [Требуется ключ]             |  <- Заблокировано (Приглушенный серый)    |
|  +-------------------------------------+                                           |
|   (Прокрутка: Колесо мыши | Выбор: [F])                                            |
+------------------------------------------------------------------------------------+
   ^ Меню зафиксировано в левом нижнем углу над панелью чата / брони
```

### Геометрия и позиционирование (Левый нижний угол)

| Параметр | Значение | Описание |
| --- | --- | --- |
| **Позиция X** | `24 px` | Отступ от левого края экрана |
| **Позиция Y** | `height - 110 px` | Привязка над уровнем интерфейса здоровья/брони |
| **Ширина панели** | `210 px` | Компактный размер под краткие действия |
| **Высота пункта** | `18 px` | Высота одной строки выбора |
| **Интервал (Gap)** | `4 px` | Расстояние между пунктами списка |

### Цветовая палитра оформления (Изумрудно-зеленый стиль)

* **Фон панели:** `0xEA06140D` (глубокий тёмно-изумрудный графит).
* **Основная рамка панели:** `0x8010B981` (полупрозрачный изумруд).
* **Акцентная подсветка (Focus / Hover):** `0xFF22C55E` (яркий неоново-зеленый).
* **Фон активного пункта:** `0xD00F3D24` (насыщенный зеленый градиент/плашка).
* **Фон неактивного пункта:** `0x70092315` (приглушенный болотный).
* **Текст активного пункта:** `0xFFFFFF` (чистый белый) + зеленый индикатор `[>]`.
* **Текст обычного пункта:** `0xA7F3D0` (светло-мятный).
* **Заблокированный пункт:** `0x5006140D` (фон), `0x556B5F` (текст), метка `[x]`.

## 3. Формат конфигурации триггеров (`config/story_engine/triggers/`)

Каждый интерактивный объект или блок описывается отдельным JSON-файлом:

```json
{
  "id": "ruined_portal_console",
  "type": "block",
  "pos": [142, 70, -315],
  "dimension": "minecraft:overworld",
  "name": "Консоль портала",
  "maxDistance": 3.5,
  "outlineColor": "0xFF22C55E",
  "actions": [
    {
      "label": "Осмотреть руны",
      "dialogue": "examine_portal_console"
    },
    {
      "label": "Вставить око Края",
      "if": "item:minecraft:ender_eye 1",
      "command": "/clear @p minecraft:ender_eye 1",
      "completeTask": "portal_quest insert_eye",
      "sound": "minecraft:block.end_portal_frame.fill"
    },
    {
      "label": "Активировать ядро",
      "if": "flag:portal_core_repaired",
      "setFlag": "portal_active true",
      "storytell": {
        "speaker": "Механизм",
        "message": {"text": "§aПортал успешно откалиброван."}
      }
    }
  ]
}
```

## 4. Логика работы на клиенте

### 4.1. Детекция прицела (Raycast)

* В тике клиента запускается рейкаст взгляда игрока с шагом `0.1` на дистанцию `maxDistance`.
* Если перекрестие наведено на блок с зарегистрированным `InteractionTrigger`, объект помечается как `ActiveTarget`.

### 4.2. 3D-контур блока (`TriggerOutlineRenderer`)

* Рендерится через `RenderHighlightEvent.Block` или `RenderLevelStageEvent`.
* Отображает мягкий светящийся контур (толщина 2 px) вокруг граней целевого блока с цветом `outlineColor`.

### 4.3. Навигация скроллом и блокировка хотбара

* Событие `InputEvent.MouseScrollingEvent` перехватывается, когда есть `ActiveTarget`.
* Прокрутка вверх/вниз меняет индекс выбранного действия (`selectedIndex`), пропуская неактивные пункты (при желании) или останавливаясь на них с отображением причины блокировки.
* Событие отменяется (`event.setCanceled(true)`), предотвращая смену активного слота оружия/инструмента в руках.

## 5. Архитектура классов

```text
com.storyengine.interaction/
├── data/
│   ├── InteractionTrigger.java          // Данные точки (pos, name, range, outlineColor)
│   └── TriggerAction.java               // Модель действия (label, if, dialogue, command, etc.)
├── server/
│   ├── TriggerManager.java              // Загрузка JSON, пространственный кэш чанков
│   └── TriggerActionExecutor.java       // Проверка условий и выполнение наград/скриптов
├── network/
│   ├── S2CSyncTriggersPacket.java       // Синхронизация триггеров в радиусе видимости
│   └── C2SExecuteActionPacket.java      // Отправка (triggerId, actionIndex)
└── client/
    ├── InteractionClientState.java      // Активный таргет, текущий selectedIndex
    ├── InteractionRaycastHandler.java   // Отслеживание взгляда в ClientTick
    ├── input/
    │   └── InteractionInputHandler.java // Перехват скролла мыши и клавиши действия
    └── render/
        ├── TriggerOutlineRenderer.java  // 3D-подсветка контура блока
        └── InteractionBottomLeftHud.java// Рендер зеленого меню в левом нижнем углу
```

## 6. Сетевой обмен и безопасность

1. **Игрок выбирает пункт и жмет клавишу действия:**
   Клиент отсылает `C2SExecuteActionPacket(triggerId, actionIndex)`.

2. **Сервер производит валидацию:**
   * Проверяет, что дистанция от глаз игрока до `trigger.pos` не превышает `maxDistance + 1.0` (защита от читов на дистанцию).
   * Повторно валидирует строку условий `if` через `DialogueConditionParser`.
   * Защита от флуда (cooldown 250 мс на срабатывание).

3. **Исполнение:**
   Сервер запускает заданные действия (`command`, `dialogue`, `give`, `completeTask`) и рассылает обновления состояния мира.
