# Story Engine — Dialogue System

## Проектный документ модуля диалогов (v4 — без иконок)

## 1. Концепция

**Dialogue System** — модуль Story Engine для создания интерактивных ветвящихся диалогов с условиями, вариантами ответов и действиями.

**Ключевые принципы:**

- **Сервер — источник истины:** Клиент получает только данные текущего узла и состояние доступности ответов. Валидация выбора происходит на сервере.
- **Минималистичный кинематографичный UI:** Полноэкранная нижняя панель диалога с выступающей плашкой имени и текстовым полем без лишних визуальных элементов (иконок/аватаров).
- **Живой мир:** Диалоговый экран не ставит одиночную игру на паузу (`isPauseScreen() = false`), мобы и частицы мира продолжают рендериться.
- **Папка = диалог, файл = узел:** Отсутствие громоздких древовидных JSON. Структура разбита на атомарные файлы.
- **Hot-reload:** Перезагрузка диалогов на лету из `config/` без перезапуска клиента/сервера.
- **Плоские действия:** Простые поля реакций в объекте ответа вместо вложенных массивов.
- **Ленивая загрузка:** Диалоги читаются с диска и кэшируются только при первом обращении.

## 2. Файловая структура

```text
config/story_engine/dialogues/
├── elder_greeting/              ← ID диалога = имя папки
│   ├── _meta.json               ← мета: title, entry, speakerDefault
│   ├── start.json               ← ID узла = имя файла (без .json)
│   ├── knows.json
│   ├── angry.json
│   └── helpful.json
└── tavern_bartender/
    ├── _meta.json
    ├── greeting.json
    ├── serve.json
    └── rumors.json
```

Запуск: `/dialogue start @p elder_greeting` → мод открывает папку `elder_greeting/`, парсит `_meta.json` и загружает узел `start.json`.

## 3. `_meta.json`

Мета-информация диалога со значениями по умолчанию:

```json
{
  "title": "Встреча со старостой",
  "entry": "start",
  "speaker": "Староста"
}
```

| **Поле** | **Тип** | **Описание** |
| --- | --- | --- |
| `title` | string | Название диалога (для логов и отладки) |
| `entry` | string | ID стартового узла (имя входного файла) |
| `speaker` | string | Имя спикера по умолчанию |

## 4. Формат узла диалога (`<node_id>.json`)

Каждый файл описывает отдельный шаг диалога.

```json
{
  "text": "Здравствуй, путник. Что привело тебя в наши края?",
  "speaker": "Староста",
  "responses": [
    {
      "text": "Я ищу древний ключ.",
      "next": "knows"
    },
    {
      "text": "§cНе твоё дело, старик.",
      "command": "/quest start @p bandit_path",
      "next": "angry"
    },
    {
      "text": "[Убеждение] Мне нужна ваша помощь.",
      "if": "quest:village_in_danger:active",
      "completeTask": "village_in_danger talk_to_elder",
      "next": "helpful"
    }
  ]
}
```

| **Поле узла** | **Тип** | **Описание** |
| --- | --- | --- |
| `text` | string | Текст реплики NPC (выводится печатным эффектом) |
| `speaker` | string? | Локальное переопределение имени для данного узла |
| `responses` | Response[] | Варианты ответа игрока |

## 5. Формат ответа (`Response`) и плоские действия

```json
{
  "text": "Договорились, вот изумруды.",
  "if": "item:minecraft:emerald 3",
  "next": "deal_done",
  "close": false,
  "command": "/clear @p minecraft:emerald 3",
  "startQuest": "ancient_relics",
  "completeTask": "main_story talk_elder",
  "storytell": {
    "speaker": "Староста",
    "message": {"text": "Береги себя в пути."}
  },
  "give": "minecraft:iron_sword 1",
  "setFlag": "elder_trust true",
  "xp": 15
}
```

| **Поле** | **Тип** | **Описание** |
| --- | --- | --- |
| `text` | string | Текст кнопки выбора |
| `if` | string? | Условие доступности варианта |
| `next` | string? | Переход к следующему узлу |
| `close` | boolean? | `true` — закрыть диалог |
| `command` | string? | Выполнить команду сервера (`@p` → игрок) |
| `startQuest` | string? | ID квеста для запуска |
| `completeTask` | string? | `"questId taskId"` — завершить этап квеста |
| `storytell` | object? | Отправить реплику в Narrative HUD |
| `give` | string/object? | Выдать предмет |
| `setFlag` | string? | `"flag_name true/false"` — установить сюжетный флаг |
| `xp` | int? | Выдать опыт |

**Порядок исполнения на сервере:** `command` → `startQuest`/`completeTask` → `give`/`xp`/`setFlag` → `storytell` → `next`/`close`.

## 6. Синтаксис условий (`if`)

```text
"if": "quest:village_in_danger:active"
"if": "item:minecraft:emerald 3"
"if": "task:find_key reach_mill"
"if": "flag:met_elder"
"if": "not:quest:bandit_path:completed"
```

| **Префикс** | **Формат** | **Проверка** |
| --- | --- | --- |
| `quest` | `quest:<id>:<status>` | Статус квеста (`active`, `completed`, `failed`, `not_started`) |
| `item` | `item:<itemId> <count>` | Предмет в инвентаре |
| `task` | `task:<questId> <taskId>` | Подзадача квеста |
| `flag` | `flag:<flagId>` | Булев флаг игрока (`true`) |
| `not` | `not:<condition>` | Отрицание вложенного условия |

## 7. Компоновка интерфейса (`DialogueScreen`)

### Схема экрана

```text
+------------------------------------------------------------------------------------+
|  [>] 1. Кто ты такой?                                                              |
|  [>] 2. Где найти кузнеца?         <- Варианты ответов (слева вверху)              |
|  [>] 3. [Заблокировано]            <- Серый неактивный пункт                       |
|                                                                                    |
|                                                                                    |
|                                                                                    |
|    +--------------------+                                                          |
|    |  Староста          |          <- Плашка имени спикера (внахлёст на 1px)       |
|  ==+====================+=======================================================+  |
|  |  "Дорога на север перекрыта стражей. Если хочешь пройти через перевал,       |  |
|  |   тебе потребуется специальный пропуск градоначальника."                     |  |
|  +==============================================================================+  |
+------------------------------------------------------------------------------------+
   ^ Нижняя полоса растянута на 100% ширины экрана (0 .. screenWidth)
```

### Спецификация элементов

**1. Нижняя полоса реплики:**

- **Габариты:** Позиция `X = 0`, `Y = height - 68`, ширина `width` (во всю ширину экрана), высота `68 px`.
- **Фон:** Тёмно-графитовый `0xEA0E1117`.
- **Разделитель:** Тонкая верхняя линия `0x604A5568` толщиной 1 px.
- **Текст реплики:** Начинается с отступом `32 px` слева и занимает всю доступную ширину до правого края (отступ `32 px` справа). Текст выводится через `TypewriterEngine` (~25 симв/сек) и вертикально центрируется внутри полосы.

**2. Плашка имени:**

- **Габариты:** Высота `16 px`, ширина `font.width(speaker) + 20 px`.
- **Позиция:** `X = 32 px` (выровнена с началом текста реплики), `Y = height - 68 - 15` (лежит внахлёст на 1 px).
- **Стиль:** Фон `0xEA0E1117`, рамка `0x604A5568`, верхняя акцентная полоса `0xFF38BDF8`, текст имени — `0xFFE066`.

**3. Варианты ответа (Слева вверху):**

- **Позиция:** `X = 24 px`, `Y = 24 px`.
- **Размер плашки выбора:** `220 × 20 px`, отступ между строками `6 px`.
- **Интерактивность:**
  - *По умолчанию:* Фон `0x8010141D`, рамка `0x604A5568`, текст `0xCCCCCC`.
  - *Hover:* Фон `0xD81E293B`, рамка `0xFF38BDF8`, текст `0xFFFFFF`.
  - *Заблокировано:* Фон `0x40000000`, рамка `0x30FFFFFF`, текст `0x777777`.
- **Ввод:** Клик мышью или цифровые клавиши `1`–`9`.

## 8. Архитектура классов

```text
com.storyengine.dialogue/
├── data/
│   ├── DialogueMeta.java             // title, entry, speaker
│   ├── DialogueNode.java             // text, speaker?, responses[]
│   └── DialogueResponse.java         // text, плоские поля действий, if
├── condition/
│   ├── DialogueCondition.java        // Базовый интерфейс условий
│   └── DialogueConditionParser.java  // Парсер строковых условий
├── server/
│   ├── DialogueManager.java          // Ленивая загрузка, кэширование, reload
│   ├── DialogueSession.java          // Активная сессия игрока
│   └── DialogueActionExecutor.java   // Выполнение действий ответа
├── network/
│   ├── S2COpenDialoguePacket.java    // Передача узла (текст, имя, список ответов)
│   ├── S2CUpdateDialoguePacket.java  // Обновление диалога при переходе
│   ├── S2CCloseDialoguePacket.java   // Закрытие окна
│   └── C2SSelectResponsePacket.java  // Выбор ответа (responseIndex)
└── client/
    ├── gui/
    │   └── DialogueScreen.java       // Полноэкранный GUI без иконки
    └── util/
        └── TypewriterEngine.java     // Посимвольная печать текста
```

## 9. Сетевое взаимодействие

1. **Сервер → Клиент (`S2COpenDialoguePacket` / `S2CUpdateDialoguePacket`):**
   - Передаёт `speaker`, `text`, список вариантов `List<ResponseItem>` (`String text`, `boolean isEnabled`).

2. **Клиент → Сервер (`C2SSelectResponsePacket`):**
   - Отправляет индекс нажатой кнопки `responseIndex`.

3. **Серверная валидация:**
   - Проверка наличия `DialogueSession`.
   - Rate Limit (≥ 200 ms) против спама кликами.
   - Проверка валидности индекса и условий `if`.
   - Выполнение действий через `DialogueActionExecutor` и переход/закрытие.
